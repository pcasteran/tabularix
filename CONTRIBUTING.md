# Contributing to Tabularix

Please refer to the full **[Contributing & Development Guidelines](docs/contributing.md)** in the `docs` directory for:

- Environment setup (`mise install`, `just build`).
- Running linters and checkers (`just prek`).
- Running unit and acceptance tests (`just unit-test`, `just acceptance-test`).
- Documentation builds (`just docs-serve`, `just docs-build`).
- Release workflows (`just prepare-release`).
